# Wallpaper licenses

Each wallpaper's license is in its `license` field in `catalog.json`.

The starter pack (`t01`–`t05`, `a01`–`a05`) was generated by `tools/paint.py` and is dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Use it anywhere.

Lettering in the starter pack uses Fredoka, Permanent Marker (Apache 2.0), DM Serif Display and Anton
(SIL OFL 1.1), via the @fontsource packages.
